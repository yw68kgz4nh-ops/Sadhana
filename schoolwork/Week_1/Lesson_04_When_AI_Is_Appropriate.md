# Lesson 4 — Is AI the Right Tool for This Problem?

**Estimated time:** 35–45 minutes  
**Status:** 🟠 Prepared study paper; not yet taught or assessed.

## Learning goals

By the end, you should be able to compare an AI-based idea with simpler alternatives, identify the risks that matter, and explain why AI is or is not justified for a particular task.

## Start with the problem

Before selecting a technology, return to the person, goal, context, difficulty, and evidence. Ask what a successful outcome looks like. A proposal that uses AI is not automatically better than one that does not.

## Compare alternatives

For a specific problem, consider at least:
- **No change:** keep the existing process.
- **Non-AI improvement:** clearer instructions, better search, a form, a checklist, or simpler navigation.
- **AI-assisted option:** use AI for a task where flexible language or pattern handling may help.
- **Human-led option:** keep a person responsible for judgement or decisions that need accountability.

Compare the options using usefulness, effort, reliability, accessibility, privacy, cost, speed, and recovery when something goes wrong.

## Worked example

A learner struggles to find the latest lesson notes.

- A better folder structure and clear index may solve the problem directly.
- AI might help search natural-language descriptions across many documents.
- A chatbot that invents a location or claims a file exists when it does not would make the problem worse.

The simplest option that meets the user's needs may be the best design.

## Practical exercise

Choose a real problem from an app or service. Write:
1. The person, goal, context, and difficulty.
2. One non-AI solution.
3. One AI-assisted solution.
4. Two likely failure cases for the AI option.
5. How the user would detect and recover from each failure.
6. Which option you would test first, and why.
7. What evidence could change your mind.

## Recall check

- Why is “use AI” not a problem statement?
- Name two situations where a simpler non-AI solution might be preferable.
- What recovery action should exist when an AI result is wrong?
