## Rules for new improvements
1. Check the index for an existing matching issue before creating an ID.
2. Keep an actual report or evidence separate from suspected cause and solution.
3. Record the user goal, main flow, alternatives, acceptance, failures and test.
4. Link relevant research and coursework, but don't duplicate case files.
5. Record whether the case is draft, implemented, user-reviewed and tested separately.
6. Do not upload private or sensitive source materials to this public repository.
