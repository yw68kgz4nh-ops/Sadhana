# Project Management

This folder holds the project's scope, working agreements, current status, work log, and coordination notes.

## Core records

- [Current status](STATUS.md)
- [Work log](WORK_LOG.md)

## Working agreement

- Verify actions rather than relying on claims.
- Keep one authoritative record for each important item.
- Record decisions and unresolved questions.
- Keep plans distinct from work actually completed.
- Update the work log and status when meaningful project changes occur.
- The repository is public; do not commit confidential or sensitive material.
