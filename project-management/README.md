# Project Management

This folder holds the project's scope, working agreements, current status, work log, workflow diary, and coordination notes.

## Core records

- [Current status](STATUS.md)
- [Work log](WORK_LOG.md) — concise record of meaningful project changes
- [Workflow diary](WORKFLOW_DIARY.md) — session and milestone recaps, including aims, decisions, completed work, verification, hurdles, and next steps

## Working agreement

- Verify actions rather than relying on claims.
- Keep one authoritative record for each important item.
- Record decisions and unresolved questions.
- Keep plans distinct from work actually completed.
- At the close of each meaningful session or project phase, add a workflow diary recap.
- Update the work log and status when meaningful project changes occur.
- The repository is public; do not commit confidential or sensitive material.
