# Sadhana Prompt Library

This is the authoritative repository location for Sadhana prompts.

## Structure

- [Master prompt v0.5](master/Shared_AI_Working_Philosophy_v0.5.md) — current shared working philosophy, including mandatory journalling of meaningful design changes, fixes, decisions, and verification.
- [Master prompt v0.2](master/Shared_AI_Working_Philosophy_v0.2.md) — preserved earlier version.
- [Prompt library index](library/README.md) — inventory and migration status for task-specific prompts.

## Versioning rule

Do not silently overwrite a meaningful prior version. When a prompt changes materially, preserve the previous version where useful, update the version and change notes, and verify the saved file.

## Migration status

The current working-philosophy prompt is versioned in the repository. Other prompt drafts discussed in ChatGPT conversations are not all available as complete source files yet, so they must be reconciled before being described as fully migrated.

## Current master prompt

- [Shared AI Working Philosophy v0.5](master/Shared_AI_Working_Philosophy_v0.5.md) — retains v0.4's acknowledgement and task-feedback rules, and adds a mandatory journal-every-meaningful-change rule, including retrospective recording of earlier omissions.
- [Shared AI Working Philosophy v0.4](master/Shared_AI_Working_Philosophy_v0.4.md) — preserved prior version: explicit request acknowledgement, progress feedback, completion/verification distinctions, and honest failure/unfinished-task reporting.
