# Evidence and Verification

Store or index evidence that supports project claims, tests, and decisions. Prefer links to authoritative sources and keep source dates and limitations where relevant.

## Current register

- [Sadhana Evidence Register](EVIDENCE_REGISTER.md) — initial mapping of reported UX observations, repository checks, confidence limits, and next evidence-gathering actions.

## Evidence rules

- Identify whether an item is a direct observation, user report, transcript, screenshot, tool result, external source, or usability-test result.
- Record dates, device/context, and reproduction steps when available.
- Separate observation from interpretation and proposal.
- State what the evidence does not establish; do not generalise one user's experience to all users.
- Link evidence to the related use case, experiment, or decision.
- Verify saved files by reading them back where possible.
- Do not store credentials, secrets, private personal data, or confidential records in this public repository.
