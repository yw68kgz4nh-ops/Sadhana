# Sadhana

Sadhana is a research and development project exploring a more effective human–AI working partnership: reliable, transparent, accessible, continuous, and capable of making practical progress with less unnecessary work for the person.

## Repository map

- [Project management](project-management/README.md) — scope, status, and working agreements.
- [Master prompts](prompts/README.md) — common working philosophy and prompt library.
- [Research](research/README.md) — questions, findings, and research notes.
- [Use cases](use-cases/README.md) — observed problems, needs, and opportunities.
- [Experiments](experiments/README.md) — tests, prototypes, and outcomes.
- [Decisions](decisions/README.md) — decisions, rationale, and open questions.
- [Evidence](evidence/README.md) — source material and verification records.
- [Archive](archive/README.md) — superseded material retained for traceability.

## Working rules

1. Distinguish observed facts, hypotheses, proposals, decisions, attempted actions, completed actions, and verified outcomes.
2. Check capability and permission before promising execution.
3. Record meaningful failures as research evidence, including impact, tests, results, and remaining uncertainty.
4. Prefer one authoritative record and avoid competing copies.
5. Verify repository changes after writing them.
6. Keep private or sensitive information out of this repository.

## Privacy and visibility

**This repository is public.** Do not commit passwords, access tokens, private personal information, confidential records, or material that should not be public.
