# Sadhana

Working repository for the Sadhana human–AI working-partnership research.

## Purpose

Develop and evaluate a reliable, transparent human–AI partnership that supports continuity, organised knowledge, feasible execution, and learning from real-world obstacles.

## Working principles

- Distinguish facts, hypotheses, proposals, attempts, completed actions, and verified outcomes.
- Check tools, permissions, and capabilities before promising an action.
- Capture meaningful failures and limitations as research evidence.
- Prefer one authoritative record over scattered duplicates.
- Verify changes after writing them.
