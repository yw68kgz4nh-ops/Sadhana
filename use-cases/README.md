## Record fields

- Intended outcome and context
- Observed behaviour and evidence
- Impact on the person or work
- Verified facts, separated from hypotheses
- Options and proposed solution
- Tests, results, status, and follow-up
- Related files and decisions

Before creating a new record, check for an existing matching issue and update it where appropriate. Drafts should be strengthened with further evidence and validated tests as the project proceeds.
