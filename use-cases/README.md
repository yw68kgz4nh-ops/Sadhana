## Record fields

- Intended outcome and context
- Observed behaviour and evidence
- Impact on the person or work
- Verified facts, separated from hypotheses
- Options and proposed solution
- Acceptance criteria and failure cases
- Tests, results, status, and follow-up
- Related files, evidence, and decisions

Before creating a new record, check for an existing matching issue and update it where appropriate. Drafts should be strengthened with original evidence and validated tests as the project proceeds. Some records intentionally overlap pending consolidation; do not treat each ID as a proven, independent defect.
