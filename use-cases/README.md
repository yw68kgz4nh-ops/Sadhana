# Use Cases and Problem Records

Record observed user needs, friction, limitations, failures, and opportunities for improvement.

## Suggested record contents

- ID and short title
- Intended outcome and context
- Observed behaviour and evidence
- Impact on the person or work
- Hypotheses, clearly separated from facts
- Options and proposed solution
- Tests, results, status, and follow-up
- Related files and decisions

Before creating a new record, check for an existing matching issue and update it where appropriate.
